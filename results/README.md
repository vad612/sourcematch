# Результаты итераций

Снимки показывают, как менялись рекомендации, подбор и оценка риска. В колонке штрафа меньшее число лучше. Штраф считается на 300 карточках с ответами заказчика. Число ручных проверок в правой колонке относится ко всей выгрузке на 3 700 карточек.

Базовый результат для сдачи — [submission.csv](../submission.csv). Его SHA‑256 — `ec5948e7f33ffb52051861203fe2ba4159a5fb7a06a2e3dd1555fd41b765fd07`. Вариант с повышенным риском доступен отдельным [полным CSV](iteration-04-risk/pilot-submission.csv). [Сводка сильного стресса](iteration-04-risk/stress-summary.json) показывает вложенный капитал, стоимость остатка, вклад и убытки отдельных позиций. Это расчётный сценарий на данных задачи. [Эвал языкового расширения](iteration-04-risk/matching-evaluation.json) содержит результаты по полям и локалям.

CSV и отчёты эвалов скопированы из локальных прогонов. Для CSV, сопровождаемых манифестом, при копировании сверены хеши. Из финансового сравнения сохранены агрегаты и число карточек с изменённым решением. Кеши моделей, журналы SQLite и машинно-зависимые пути остаются в локальной папке `runs/`.
