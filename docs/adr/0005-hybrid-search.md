# ADR 0005. Векторный поиск и BM25 внутри CLI

## Контекст

Векторный канал ищет межъязыковые аналоги. Сопоставление размеров, серии и материала требует независимых сигналов. Для прототипа объём каталога составляет около 10 тысяч предложений.

## Решение

Уточнено при реализации. Точный поиск выполняется пакетным умножением нормализованных векторов в `ndarray`. Лексический индекс SQLite FTS5 с BM25 использует те же готовые зависимости, что и журнал. Это позволяет развернуть прототип одним Rust-бинарником и пересоздавать индекс из новой выгрузки. Переход к другому движку оценивается по полноте, времени и требованиям к сборке. [SQLite FTS5](https://sqlite.org/fts5.html), [ndarray](https://docs.rs/ndarray/latest/ndarray/)

## Запрос и выдача

- Лексический канал использует токены заголовка и нормализованные ключи признаков. Запрос собирается из экранированных токенов и передаётся как параметр.
- Кандидат содержит ранги каналов и признаки поиска по ключу модели. Ранги объединяются RRF, при равенстве используется ID предложения. Кандидаты с тем же распознанным типом, материалом и серией добавляются независимо от ранга и проходят проверку остальных обязательных признаков.
- Профиль задаёт начальный и расширенный объёмы выдачи. Расширение текущего прототипа используется для карточек без полного ключа или без предложений по ключу. Индекс строится из каждой выгрузки. Кешируются векторы текста, цены и логистика загружаются заново.
- Кандидаты поступают в проверку совпадения и реранжирование. Выбор предложения для расчёта учитывает все подтверждённые варианты. [ADR реранжирования](0015-reranking.md), [ADR закупки](0007-procurement.md)

## Проверка

Проверяем наличие аналога среди кандидатов каждого канала и в итоговой тройке. На текущей размеченной выборке в объединённой выдаче найден хотя бы один аналог у всех 264 карточек с эталонным совпадением. Режим нескольких воркеров повторяет порядок и результат. Для другой выгрузки остаются проверки полноты, чувствительности к объёму выдачи и наличия самого дешёвого аналога там, где его можно установить.
