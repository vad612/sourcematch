# ADR 0002. Импорт CSV и публикация результата

## Контекст

Выгрузки содержат пропуски и дубли. На защите одна колонка спроса исчезнет. Выход должен сохранить порядок и поля шаблона.

## Решение

Используем `csv` и `serde`. Адаптер связывает колонки источника с внутренними полями через версионированный профиль, проверяет единицы, требуемые на уровне схемы, и сохраняет `file/row/column` для диагностики. Входная кодировка UTF‑8 с допустимым BOM. Новая кодировка или разделитель задаются профилем источника. [CSV и Serde](https://docs.rs/csv/latest/csv/)

## Контракт

- Колонки разрешаются по имени или явному синониму из профиля, независимо от порядка. Дополнительные колонки допустимы. Отсутствующие колонки спроса, цены, характеристик, веса и упаковки передаются как пропуски. Ошибка разбора значения помечает поле с указанием строки и причины.
- Совпадающие строки с одним ключом схлопываются. При конфликте сохраняются согласованные поля, спорные факты считаются неизвестными и учитываются только в затронутых карточках. Дубли товара с разными ID сохраняются как самостоятельные входы. Перестановка конфликтующих строк даёт тот же результат.
- Если строка шаблона ссылается на отсутствующую карточку, сохраняем её ID и формируем `проверить вручную` с `NO_MATCH` и явной причиной «карточка отсутствует во входе». Если у строки источника нет ID, фиксируем её отдельно в диагностике. Весь запуск прерывается при нечитаемой структуре файла, отсутствии колонки ключа или повторе ID в самом шаблоне.
- При наличии шаблона назначаем `ordinal` по его строкам, иначе по карточкам во входе. Каталог и шаблон можно опустить. Итоговый файл содержит только поля шаблона, значения `decision` дословно, аналоги через `;`, неизвестные деньги пустыми.
- Записываем файл во временное имя в каталоге назначения, сбрасываем буферы и публикуем через `NamedTempFile::persist` на той же файловой системе. Перед публикацией сверяем число строк и уникальность ключей. Манифест хранит хеш выпущенного файла. [Tempfile](https://docs.rs/tempfile/latest/tempfile/struct.NamedTempFile.html)

## Проверка

Нужны примеры с перестановкой и добавлением колонок, исчезновением каждой оценки спроса и обеих сразу, кавычками и переносами внутри текста, BOM, совпадающими и конфликтующими дублями, потерей записи шаблона и сбоем до публикации. Одиночная неполная строка или конфликт ID не меняют выводы для незатронутых карточек. Профиль источника описывает изменения схемы, общие правила расчёта используются для всех входов.
