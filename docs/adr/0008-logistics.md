# ADR 0008. Вес, упаковка и источники данных

## Контекст

У 2 946 предложений нет веса, у 4 827 нет габаритов упаковки. У 429 из 1 500 записей российского каталога нет `offer_id`. Вес транспортного короба и объём упаковки покупательской единицы могут относиться к разным объектам. [Предложения](../../input/offers%20%281%29.csv), [каталог](../../input/ru_catalog%20%281%29.csv)

## Решение

Для выбранного предложения возвращаем три независимых значения на единицу карточки. Это вес для доставки, объём для доставки и объём единицы для тарифа площадки. Каждое несёт источник, тип упаковки и статус `known / bounded / unknown`. Когда выбор не определён, те же измерения запрашиваются для возможных вариантов, которые нужны для оценки границ маржи. Совпадающие поиски по каталогу переиспользуются внутри прогона.

## Реализация

- Брать сведения из предложения, если известно, за что они указаны. Короб делить на число единиц после проверки комплектности и области измерения. Сведения о потребительской упаковке брать из отдельного поля или подтверждённого факта о её совпадении с транспортной.
- Текущий прототип дополняет данные по записи каталога с тем же `offer_id` и подтверждёнными моделью, комплектом и упаковкой. При выборе нескольких возможных предложений входные сведения проверяются для каждого. Поиск по непривязанным позициям каталога рассматривается отдельно, когда можно подтвердить сопоставимость упаковки.
- Для набора из целого числа поставщицких единиц общий грузовой объём равен объёму одной такой упаковки, умноженному на их количество. Габариты внешнего транспортного короба без надёжного пересчёта исключаем. Объём упаковки готового набора для площадки определяем отдельно. Вес с явным указанием штуки умножаем на число предметов, а брутто короба с числом наборов пересчитываем на число закупаемых наборов.
- При расхождении надёжных источников передавать конфликт и оба происхождения. Для исторических позиций сохранять ссылку на запись. Историческая цена не участвует в выборе текущей закупочной цены.

## Проверка

Проверяем китайские единицы, вес штуки в предложении наборов, брутто короба с известным и неизвестным количеством и сборку набора из отдельных упаковок. При сборке сверяем отдельно объём для доставки и наличие объёма упаковки для площадки. По аудиту можно проследить происхождение параметров.
