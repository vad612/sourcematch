# ADR 0001. Один CLI на Rust

## Контекст

Заказчику нужна одна команда для новой выгрузки, а разработке нужны воспроизводимые прогоны и возможность отдельно проверять каждый этап.

## Решение

Один Cargo-пакет с бинарником `sourcematch` и модулями из [карты архитектуры](../technical-architecture.md). `app` собирает зависимости и запускает конвейер. Модули вычислений вызываются из библиотеки, чтобы CLI, интеграционные тесты и симуляции использовали один и тот же код. Разбор команд делегируем `clap`, чтение типизированных профилей — `serde` и `toml`. [Clap](https://docs.rs/clap/latest/clap/), [Serde](https://serde.rs/)

| Команда | Контракт |
| --- | --- |
| `prepare` | Проверить доступность уже запущенных локальных API и нужных моделей. Выполнить короткие запросы на синтетических данных, если модели готовы |
| `run` | Прочитать выгрузки и профиль, подготовить индексы, выпустить `submission.csv` и сохранить диагностику |
| `inspect` | Прочитать объяснение и данные одного прогона по `listing_id` из журнала |
| `evaluate` | Сопоставить готовый прогон с заданной разметкой и контрольными расчётами |
| `simulate` | Создать синтетический набор или прогнать сценарии через тот же конвейер |

## Реализация и проверка

- Типы ядра различают единицы карточки, единицы поставщика, CNY и UZS. Для существенных полей сохраняем значение, происхождение и статус `known / bounded / unknown`. Так модули могут передавать диапазон цены и объяснять пропуск.
- Профиль страны содержит курс, тарифы, материалы, сертификацию и пороги. Профиль поиска содержит loopback-адреса, идентификаторы обеих моделей, пределы кандидатов и параллелизма. Профили импорта задают имена и семантику полей источника. Схемы и хеши профилей записываются в манифест.
- Фиксируем `Cargo.lock`, версию Rust, идентификаторы и доступные версии моделей и серверов. Команды проекта проверяют настроенные зависимости и отвечают диагностикой, если недоступна обязательная возможность. Настройку среды определяет эксплуатационный профиль.
- Приёмка включает один запуск с доступом только к loopback, повторный запуск с теми же входами и смену только профиля страны для второго сценария. Один CLI координирует расчёт и вывод. Границы внутри пакета позволяют вынести этап отдельно, если измерения покажут необходимость.
