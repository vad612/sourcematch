# ADR 0014. Синтетические наборы и финансовые сценарии

## Контекст

Поставленная разметка ограничена и не содержит эталонных сумм. Для проверки нужны случаи с известными истинными ценами, весом, объёмом и спросом.

## Решение

`simulate --seed 42 --out-dir runs/synthetic` создаёт входные CSV, правила сценария и независимые эталоны. Ставки берутся из профиля, который можно передать через `--rules`. Эталонный расчёт работает с исходными величинами фикстур, отдельно от парсинга и расчётов конвейера. Синтетические данные проходят через обычный `run`, затем `evaluate --verify-synthetic` сверяет полный результат. Меняемые входы выбираются воспроизводимо по SHA-256 от seed и индекса. Свойства вычислений проверяются через Proptest. [Proptest](https://proptest-rs.github.io/proptest/intro.html)

| Набор | Проверка |
| --- | --- |
| Контрольные строки | Базовый расчёт с ручной сверкой для двух профилей, резкий скачок курса, отсутствие или расхождение оценок спроса, пограничный прогноз, новая сертификация, неизвестный вес, сборный набор, диапазон закупочных цен, граница тарифа, доставка по объёму и превышение MOQ |
| Портфель на 32 товара | Те же товары проверяются при исходных условиях, курсе на 20% выше и спросе на 20% ниже. Oracle рассчитывает суммы и причины независимо от производственного модуля |
| Волны скоринга | Два набора с одинаковыми наблюдаемыми входами и разными скрытыми исходами. Вес выбранного предложения может совпасть с диапазоном или выйти за него. Фактические продажи могут подтвердить или опровергнуть прогноз |
| Парное изменение формата | Копия выгрузки с перестановкой полей и удалением одного источника спроса. Совмещённая проверка применяет также новый курс и категорию сертификации |
| Свойства расчёта | Проверяем эквивалентность единиц, допустимость граничных значений, монотонность маржи при изменении курса, детерминизм при смене числа воркеров |

## Финансовый отчёт

Для сценария измеряем закупочный капитал, капитал по ложным запускам и капитал в непроданном остатке через месяц. Эталон содержит цену на складе, размер партии и спрос за месяц. Остаток ограничивается нулём. Результаты описывают параметры синтетического сценария и проверяют чувствительность к изменению условий.

Для новых сценариев дополнительные колонки эталона содержат себестоимость и маржу из скрытых исходов и признак прохождения закупочных условий по этим исходам. Финансовый эвал умножает маржу на фактические продажи в пределах партии, показывает вложенный и непроданный капитал, долю сопоставимых исходов и пропущенную положительную маржу. Строгая проверка CSV использует поля ожидаемого ответа на видимых данных.

Сравниваем текущий прогон со старыми решениями, применёнными к новому сценарию. Финансовые суммы синтетики хранятся отдельно от оценки по реальным карточкам. [ADR эвалов](0013-evaluation.md)
